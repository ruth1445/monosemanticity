Path 03 · The untangling

Mono­semanticity

Superposition hid the model's concepts by rotating them off the axes. This path is the counter-move: a way to rotate them back — so that each unit means exactly one thing. That property is called monosemanticity, and in 2023 Anthropic showed how to manufacture it.

01The idea

Every thought is a recipe — find the ingredients

Recall the two facts we've earned. From Path 01: a thought is a blend of concept-directions. From Path 02: those concepts are sparse — only a handful are active at once. Put together, every activation the model ever produces should decompose like this:

activation ≈  3.2 × ARABIC SCRIPT + 1.1 × FORMAL TONE + 0.0 × DNA + 0.0 × HTTP + … thousands more at zero

If we could recover the full ingredient list — the model's dictionary of concepts — reading its mind becomes looking up which ingredients are active. The method is called dictionary learning.

02The machine

The sparse autoencoder

The tool is a small helper network — a sparse autoencoder (SAE) — trained on millions of the model's activations with two competing goals: reconstruct the activation faithfully, and use as few dictionary slots as possible. Faithful + sparse is exactly the signature of the true ingredients — so that's what the machine is forced to discover.

Anthropic ran it on a small transformer: 512 tangled neurons in, 4,096 clean features out. Watch the middle layer — only a few slots light up for any given thought:

Compress-side in · one-concept-per-slot out

The SAE never touches the model — it's a lens, not surgery. Same activations, new coordinates: one axis per concept.

03What came out

Features that mean exactly one thing

The output was the result that named the paper. Where raw neurons were soup, the learned features were monosemantic — each firing for one nameable pattern, checkable by looking at exactly which text lights it up. Same network, same activations — the SAE's coordinates simply carve the model at its joints. Sparsity, the thing that made superposition possible, is also what makes it reversible.

04The proof

Features are causal, not just correlated

A fair objection: maybe "features" are shapes we're seeing in clouds. The test is intervention. If the DNA feature really is the model's concept of DNA, then forcing it on should change what the model does — not just what we observe. It does:
